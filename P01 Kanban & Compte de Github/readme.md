# P01: Kanban & Compte de GitHub

## 📝 Breu Descripció

Aquest producte combina dues eines essencials per al treball professional dins la consultora **EverPia**:

* **Gestió visual de tasques:** Ús de la metodologia Kanban mitjançant *Microsoft Planner*.
* **Espai de treball individual:** Creació i ús d’un repositori personal a *GitHub* per a la documentació tècnica.

Ambdues eines asseguren que cada grup i alumne disposi d'un sistema d'organització clar, transparent i professional, alineat amb els estàndards reals del sector IT.

---

## 🎯 Objectius de la Tasca

* **Coordinació Col·laborativa:** Garantir que cada grup disposa d'una eina de gestió eficient (Planner).
* **Espai Individual:** Assegurar que cada alumne té un espai propi de treball i documentació (GitHub).
* **Cultura Professional:** Reforçar el compromís amb la metodologia d'EverPia: transparència, organització i traçabilitat del treball.

---

## 🛠️ Desenvolupament de la Tasca

### Part 1: Tauler Kanban (Microsoft Planner) - Treball en Grup

Cada grup ha de crear un tauler Kanban a Microsoft Planner que compleixi els següents requisits:

* **Columnes mínimes obligatòries:**
1. 📋 **Backlog:** Llista de totes les tasques pendents del projecte.
2. ⚙️ **En curs:** Tasques en desenvolupament actiu.
3. 👀 **En revisió:** Tasques pendents de validació.
4. ✅ **Fet:** Tasques completades correctament.


* **Gestió del Backlog:** S'ha d'omplir des del principi amb totes les tasques assignades al projecte (T01, T02, ..., T10).
* **Manteniment:** Les tasques s'hauran d'anar movent de columna en funció del progrés real del grup.

### Part 2: Compte i Repositori GitHub - Treball Individual

Cada alumne ha de configurar el seu entorn de codi i documentació individual:

1. **Registre:** Creació d'un compte personal a GitHub (si no es disposa d'un) associat al correu de l'escola.
2. **Repositori de Presentació:** Crear un repositori públic de presentació personal.
3. **Documentació:** Redactar el fitxer README.md amb una presentació personal formal.
